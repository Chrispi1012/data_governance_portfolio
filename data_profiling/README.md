Core components of data profiling: 
  Dataset Overview: Size, row count, column count, and source system details
  Structural Analysis: Data types, formats, lengths, and uniqueness constraints
  Content Analysis: Null counts, value distributions, min/max ranges, and frequency patters
  Quality Dimensions: Scores for accuracy, completeness, consistency, and validity
  Anomaly Findings: Outliers, duplicate records, mismatched patterns, and orphaned keys
